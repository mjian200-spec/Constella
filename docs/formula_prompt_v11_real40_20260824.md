# 公式提示词 v11：40 个真实上下文包实测

日期：2026-08-24

## 测试设置

- 模型：本地 vLLM `qwen3.8-27b`
- 输入：`outputs/context_builder_full_fresh` 中既有的 40 个真实上下文包
- 清单：`outputs/rule_extraction_cr_alignment_40_manifest.json`
- 生成提示词：`rule_generator` v11
- 反思提示词：Main v2、Full v2
- 并发：每个运行 4 worker
- Neo4j：关闭
- 第一次端到端运行使用全新输出目录，不复用旧模型输出。
- 第二次严格 A/B 使用第一次 Main 运行刚生成的同一批 40 份 v11 初稿，只重跑两版反思，以排除生成阶段波动。

## 公式专项结果

### 已达到的目标

本批所有实际输出的普通公式都进入箭头方括号，没有再出现普通公式占据箭头端点：

```text
context_000255
C: 焊接电源|恒压源 + 电阻R|忽略
R: 焊接回路|燃弧 —[L × di/dt=E-Ua]→ 电压平衡关系|成立
```

明确公式化简仍正确使用两端完整公式：

```text
context_000540
C: K0/(R0+B0K0)|等于K1 + L|约等于0
R: 式(5-30)|完整原式 —[可化简为]→ 式(5-31)|完整结果式
```

`context_000037`、`000043`、`000101`、`000176`、`000255`、`000896`、`000911` 中被抽取的普通公式均位于箭头中；`context_000540` 的公式化简位于两端。说明本轮修改对“公式位置”有效。

### 仍未通过的问题

#### context_000101：位置正确，但端点错误

核心原文说明压力差产生由电极指向焊件的推力 `Fa`，随后给出 `Fa` 方程。两版均把公式放进箭头，但没有把公式输入量和输出量正确放到两端：

```text
Main: 电弧静压力|计算 —[Fa=K3I²lg(Rb/Ra)]→ 推力Fa|由电极指向焊件
Full: 推力Fa|由电极指向焊件 —[Fa=K3I²lg(Rb/Ra)]→ 电弧静压力|数值
```

Full 方向更明显错误；参考表达：

```text
C: 无
R: 焊接电流|I + 电弧截面半径|Ra与Rb —[Fa=K3I²lg(Rb/Ra)]→ 电弧轴向推力|Fa
```

#### context_000449：核心公式遗漏

核心原文直接说脱氧核心是抑制式(5-15)反应，资源给出了完整反应式。两版只输出“抑制式(5-15)反应”，没有保留具体反应：

```text
C: 焊接方法|CO2气体保护焊
R: FeO(液)+C(液)|反应物 —[FeO(液)+C(液)⇌Fe(液)+CO(气)↑]→ Fe(液)+CO(气)|生成物
```

这说明公式位置规则已生效，但“何时核心公式必须抽取”的判断仍会漏检。

## Main / Full 关键差异

Full 的有效改进：

- `context_000003`：保留工效提高 `2~3.5倍` 的数值。
- `context_000037`：保留更规范的“气体电离能 → 气体光电离临界波长”端点。
- `context_000243`：保留“较亮球状电弧表明表面张力较大”，避免 Main 将其改成重复规则。
- `context_000392`：保留 `塞尺|检查` 的完整对象/状态。
- `context_000566`：避免 Main 把“焊缝平滑、美观”重复加入已有熔敷率规则。
- `context_000772`：把应用方向改为“短路过渡MAG焊主要用于3mm以下板厚”。

Main 的有效改进：

- `context_000172`：没有把前一句一般性的 Ar+He/H2 规律错误加入只适用于 TIG 的规则组。
- `context_000390`：删除了“图4-44展示其他接头形式”这种导航信息；Full 反而重新补入。
- `context_000101`：虽然端点仍不合格，但比 Full 把 `Fa` 指向“电弧静压力数值”更接近公式输出量。

共同未修复问题包括：

- `context_000012` 仍保留 `Hz` 疑似 `H2` 的 OCR 错误；
- `context_000132` 仍把埋弧焊、焊条电弧焊、大电流 TIG 焊三个互斥方法用 `+` 合入一个 C；
- `context_000449` 遗漏核心反应式；
- `context_000101` 公式端点语义不正确。

## 结论

1. 新公式位置规则在真实包中生效，普通公式进入箭头，明确化简公式保留在两端。
2. 仅通过格式解析仍不足：公式端点和核心公式必抽判断还有实质错误。
3. 固定初稿比较中 Full v2 明显优于 Main v2，但 Full 仍会补入导航信息或错误扩大约束作用域。
4. 下一步应只针对“公式输入/输出端点”和“正文把公式作为核心结论时必须保留完整公式”修改提示词，再复测公式相关真实包，不应立即全量运行。
