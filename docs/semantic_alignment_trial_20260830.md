## 最小协议

1. 概念融合：LLM仅输出需要合并的概念ID组。
2. 对象对齐：LLM仅输出`对象ID -> 概念ID/NEW/REPARSE/INVALID`。
3. 状态重解析：对对象级`REPARSE`逐状态选择概念ID，或输出`UNRESOLVED/INVALID`。
4. 状态规范化：LLM仅输出同义状态ID组及规范状态，或异常枚举；规范状态是否显式包含概念名只记质量指标，不作为协议失败条件。

包和结果均以输入及提示词指纹缓存；成功包可直接恢复，失败包自动重试一次。
