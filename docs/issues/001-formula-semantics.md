## 验收标准

- 普通公式只出现在箭头方括号中。
- 公式左侧表示输入量/反应物，右侧表示目标量/生成物。
- 正文把公式作为当前核心结论或明确操作对象时，完整公式不得只用式号代替。
- 使用 `context_000101`、`context_000255`、`context_000449`、`context_000540` 回归。
