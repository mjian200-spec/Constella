# 禁止在同一 C 中用加号合并互斥适用对象

## 问题

真实包 `context_000132` 把埋弧焊、焊条电弧焊和大电流 TIG 焊写成：

```text
C: 焊接方法|埋弧焊 + 焊接方法|焊条电弧焊 + 焊接方法|大电流TIG焊
```

`+` 表示条件共同成立，但三个焊接方法是并列适用对象，不可能同时成立。

## 期望

- 同一对象的互斥状态分别成组或分别作为规则主体。
- 只有原文明确要求共同成立的条件才能使用 `+`。
- 反思阶段必须优先于局部措辞修改处理组级互斥问题。

## 验收标准

- `context_000132` 不再产生互斥方法的加号 C。
- 低碳钢/普通钢、不同气体方案、不同焊接方法等并列值均逐值拆分。
- 气体混合成分等可同时成立的组合不被误拆。
