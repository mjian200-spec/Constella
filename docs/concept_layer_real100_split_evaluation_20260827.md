## 不合格IS_A

1. `L-MIG焊 IS_A 高效化焊接`：章节中的例举，不是直接分类句。
2. `二次或三次电离 IS_A 电离`：child本身是无效的并列概念。
3. `复合焊 IS_A MIG焊`：复合/使用关系被误判为IS_A。
4. `带电粒子连续流动 IS_A 气体放电`：原文是“也就是”的同义解释，应做别名/融合。
5. `电弧 IS_A 气体放电`：已有直接父类“自持放电”，气体放电是祖先。
6. `电离过程 IS_A 带电粒子的产生过程`：产生机制描述，不是显式分类。

下一步应优先完善Parent Judge：增加关系类型互斥判定、别名识别、直接性冲突消解，并在同一child同时存在父类链时只保留最近父类。
