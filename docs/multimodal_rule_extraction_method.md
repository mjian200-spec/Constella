# 图片、表格与公式的规则抽取方法、典型示例及矫正方向

## 1. 文档目的

本文基于当前 911 个真实上下文包的全量抽取结果、随机 80 包人工审核记录，以及现行生成与反思提示词，总结图片、表格和公式三类资源的规则抽取方法。

核心结论是：资源出现在上下文包中，只表示它可供核对，不表示其内容必须抽取。公式数量、表格行数、图片数量只能产生审核候选，不能直接作为“存在遗漏”的证据。

抽取质量应同时满足三个条件：

1. 证据可靠：对象、状态、关系、数值、单位和作用域均可由当前包直接证明。
2. 语义有用：内容形成完整的约束、对应、因果、比较、要求、禁止、选择、参数或公式关系。
3. 表达正确：C 与 R 归位正确，独立取值已拆分，公式位置符合语义类型，DSL 可以解析。

“可以解析”只证明格式被解析器接受，不证明规则语义正确。

## 2. 三类资源统一判定流程

### 2.1 先判断资源相关性

每个图片、表格或公式在抽取前必须归入以下一类。

| 分类 | 判定标准 | 处理方式 |
|---|---|---|
| 必须抽取 | 直接表达当前主题下完整、明确、有实际规则意义的条件、参数组合、因果、比较、选择、禁止、公式或缺陷—原因—措施关系；遗漏会使当前事实明显不完整 | 生成或补充规则 |
| 可选补充 | 举例、解释、中间计算、背景数据、重复正文结论，或是否属于抽取范围不能确定 | 不因遗漏而判错 |
| 不属于规则 | 图号、式号、目录、绘图样式、无语义原始数据、孤立数值、截断内容、无法辨认内容 | 不生成规则 |

### 2.2 再判断证据是否闭合

一条可抽取事实至少需要以下字段：

- 输入对象及状态；
- 明确关系；
- 输出对象及状态；
- 必要时还需要材料、方法、位置、阶段、环境或参数范围等作用域。

图片中只有尺寸数字但不清楚对应哪个尺寸、表格中只有数值但表头归属不明、公式只有式号没有公式正文，均不构成闭合证据。

### 2.3 最后进行 C/R 归位

对标题、临近正文、包约束、图片标注、表格行列头和正文条件逐一询问：去掉该条件后，本组规则是否会被错误扩大到其他方法、材料、缺陷、位置、工艺阶段或环境？

- 会被错误扩大，且该条件覆盖组内全部 R：写入 C。
- 是具体触发因素、阈值、选择者或原因：写在 R 左侧。
- 只是章节主题、图号、表号或远距上下文：不写入 C。
- C 与 R 左侧对象和状态完全相同：删除重复的 C，或重新划分规则组。
- 同一对象的取值互斥：拆分规则组，不能用 `+` 合并为共同条件。

## 3. 图片信息的规则抽取

### 3.1 图片承担的三种角色

图片在当前项目中主要有三种用途。

1. 独立证据：尺寸图、工艺示意图、流程图或曲线直接提供正文没有写出的完整关系。
2. 视觉核对：核对 OCR 中的字母、数字、正负号、单位、上下标、箭头方向和合并单元格。
3. 背景说明：图片只重复正文、展示外观或提供图号引用，不需要单独生成规则。

### 3.2 图片抽取步骤

#### 第一步：确定图片语义类型

- 尺寸图：识别尺寸线、引出线、箭头方向、尺寸对象和单位。
- 工艺示意图：识别部件、状态、流向、作用方向和步骤间关系。
- 曲线图：识别横轴、纵轴、曲线图例、适用条件和趋势区间。
- 扫描表格或公式：转入表格或公式专项流程，图片用于核对视觉内容。

#### 第二步：绑定图中元素与领域对象

数字不能直接作为状态写入规则，必须先确定它描述的属性。例如，同一张图中的 `0.2~0.5` 和 `5~10` 可能分别描述槽深和槽宽，不能都写成“槽隙”。

#### 第三步：判断图片是否提供新规则

- 正文已完整表达同一事实：图片只做核对，不重复生成。
- 图片补充了正文缺少的明确数值或方向：可补充规则。
- 图片只能说明“见图”“如图所示”：不抽取图号或图中位置。
- 图例、轴名或标注不清：删除不可靠候选，不猜测。

### 3.3 正例：尺寸图必须区分不同属性

真实包：`context_000391`。

核心正文说明薄板 TIG 焊可在垫板上留槽隙。关联图 4-45b 中两个尺寸标注分别为：

- 竖向槽深：`0.2~0.5mm`；
- 横向槽宽：`5~10mm`。

错误结果把两个数值都写为“垫板槽隙”：

```text
R: 垫板|留槽隙 —[允许]→ 垫板槽隙|0.2~0.5mm
R: 垫板|留槽隙 —[允许]→ 垫板槽隙|5~10mm
```

两个状态看似可解析，实际互相冲突。参考结果应绑定到两个不同属性：

```text
规则组1
C: 焊接方法|TIG焊 + 焊接对象|薄件
R: 垫板|留槽 —[对应]→ 槽深|0.2~0.5mm
R: 垫板|留槽 —[对应]→ 槽宽|5~10mm
```

这个示例说明图片核对不能停留在识别数字，还必须识别尺寸线所指向的属性。

### 3.4 反例：图号和绘图方式不是领域规则

真实包：`context_000505`。

正文已经给出短路小桥爆炸导致瞬时短路飞溅的机理。模型额外生成：

```text
R: 飞溅|瞬时短路飞溅 —[对应]→ 图5-30b|飞溅形式
```

`图5-30b` 是文档位置，不是领域对象，应删除。图片应核对飞溅形态，不应把图号写入图谱。

真实包 `context_000384` 中，“虚线表示等能量曲线、实线表示实验曲线”也是绘图表达。真正需要抽取的是“实验曲线与等能量曲线不完全一致，因此等能量曲线只能近似说明参数关系”，而不是虚线、实线本身。

### 3.5 图片专项矫正方向

#### 提示词方向

1. 只有规则字段来自图片、OCR存在易混字符、OCR与图片可能冲突，或准备根据图片增改规则时，才强制核图。
2. 明确禁止图号、子图编号、波形点位、虚线/实线样式直接成为领域规则。
3. 要求先描述“视觉标注对应的属性”，再读取数值，避免多个尺寸共用一个对象名。
4. 图片无法辨认时必须保持不确定或删除候选，不得用领域常识补字、补单位。

#### 输入组装方向

1. 除整图外，向模型提供与当前候选相关的局部裁剪图。
2. 传入视觉核对候选，例如当前 OCR、所在区域、待核字段，但不预先宣称 OCR 错误。
3. 保存图片区域坐标、来源页和原始块 ID，使人工审核能回到确切证据位置。

#### 程序校验方向

1. 同一输入对应同一属性但输出多个互斥尺寸时，生成审核候选。
2. R 中出现“图、表、式 + 编号”作为对象时，生成文档位置误抽取候选。
3. OCR 与模型结果单位不一致时标红，不自动选择其中一个。

## 4. 表格信息的规则抽取

### 4.1 表格不是单元格列表，而是层级语义

一条表格事实通常由以下内容共同组成：

```text
表题 + 分组表头 + 行头 + 列头 + 当前单元格 + 脚注/图例
```

忽略任一统领层级，都可能造成材料、焊接位置、缺陷类型、参数名称或单位错位。

### 4.2 表格必须抽取的条件

只有同时满足以下条件才抽取表格行：

1. 表题、行列头和单元格形成完整语义；
2. 表格明确表达适用参数、对象属性、材料方案、缺陷原因/措施、选择或比较；
3. 内容属于当前包核心主题；
4. 当前规则中不存在事实等价内容；
5. 合并单元格、字符和图例能够可靠辨认。

实验原始数据、数据目录、背景性能展示、重复正文结论和图例缺失的等级符号，不要求逐行生成规则。大型表格未全量抽取不自动构成遗漏。

### 4.3 表格抽取步骤

#### 第一步：重建表头路径

对每个数据单元格生成完整路径，例如：

```text
母材5083 → 角焊缝 → 板厚6.0mm → 焊丝5183 φ1.6mm
→ 焊接姿势水平 → 平均电流190A
```

该路径中覆盖整行参数的材料、接头、板厚和焊丝进入 C；焊接姿势是选择当前参数组的输入，进入 R 左侧；平均电流等参数进入 R 右侧。

#### 第二步：判断一格多值的语义

- 多个值共同组成一种气体或一套参数：可保留为一个状态，如 `Ar 65% + He 26.5% + CO2 8% + O2 0.5%`。
- 多个材料、方法、位置或方案是互斥选项：逐值拆分规则或规则组。
- 同一行包含多个独立结果属性：可以拆成多条 R，或在明确表示完整参数包时写为一个“工艺参数|完整参数组”。

#### 第三步：处理图例和等级符号

`◎、○、●、△` 等符号只有在图例明确给出排序和含义时才能转换为“优于、等同、较差”。没有图例时，符号只能原样保留供人工核对，不能凭习惯推断等级。

### 4.4 正例：合并表头形成完整参数方案

真实包：`context_000786`，表 6-37 为铝合金脉冲 MIG 焊典型参数。

其中一行的完整语义是：

```text
母材5083 + 角焊缝 + 板厚6.0mm + 焊丝5183 φ1.6mm
+ 焊接姿势水平
→ 平均电流190A、基值电流60A、电压24V、速度50cm/min、流量20L/min
```

参考 DSL：

```text
规则组1
C: 母材材质|5083 + 接头形式|角焊缝 + 板厚|6.0mm + 焊丝|5183 φ1.6mm
R: 焊接姿势|水平 —[对应]→ 工艺参数|平均电流190A、基值电流60A、电弧电压24V、焊接速度50cm/min、气流量20L/min
```

同一表中“可焊接薄板和空间焊缝”是两个独立应用对象，应拆为两条 R，不能合并为 `焊接对象|薄板和空间焊缝`。

### 4.5 正例：缺陷表的行头属于 C

真实包：`context_000801`，表 6-43 的列头为“缺陷种类｜成因｜解决措施”，选中行的缺陷为气孔，成因为保护气体不纯，解决措施为提高气体纯度并保证预热器正常工作。

“气孔”统领当前成因和措施，去掉后会把措施错误扩大到其他缺陷，因此进入 C；具体成因仍是触发措施的输入，留在 R 左侧：

```text
规则组1
C: 焊接方法|MIG/MAG焊 + 缺陷种类|气孔
R: 保护气体|不纯 —[解决措施]→ 保护气体纯度|提高
R: 保护气体|不纯 —[解决措施]→ 预热器|保证工作正常
```

### 4.6 反例：图例缺失时不能推断优劣

真实包：`context_000488`。

表格使用 `◎、○、●、△` 比较多种焊丝工艺性，但当前上下文未提供符号图例。模型仍生成大量“优于”和“等同”关系，其中甚至把同为 `◎` 的方案写成互相优于。

这种情况下应只保留正文明确说明的事实，例如：

```text
规则组1
C: 焊接位置|平焊
R: 熔渣型药芯焊丝|使用 —[获得]→ 焊道形状和外观|良好
R: 熔渣型药芯焊丝|使用 —[获得]→ 脱渣性|优良
```

不能根据未定义符号重建完整优劣排序。

### 4.7 反例：表格结构冲突时不猜测列归属

真实包：`context_000386`。

HTML 表格声明四个焊接速度列，但频率行出现五个数值。模型将 `37cm/min` 同时映射到 `≥4Hz` 和 `≥5Hz`。在没有原图可靠核对的情况下，应删除这些具体映射，只保留正文明确的“常用频率一般低于10Hz”等事实。

### 4.8 表格专项矫正方向

#### 提示词方向

1. 强制按“表题—分组表头—行头—列头—单元格”恢复语义后再生成规则。
2. 明确独立材料、位置、方法和方案逐值拆分；共同组成的气体成分或完整参数包可以合并。
3. 大表未全抽取不自动判为遗漏，只有能定位到明确必抽行时才补充。
4. 图例不全、列数冲突、合并单元格归属不明时，不生成具体比较或参数映射。

#### 输入组装方向

1. 为每个单元格提供结构化表头路径和 `rowspan/colspan` 展开结果。
2. 同时提供原始表格图片局部裁剪，用于核对 OCR 与合并关系。
3. 单独传递表题、脚注和符号图例，不能只传 HTML 主体。
4. 大型表格按语义行分块，但保留全局表头和分组表头。

#### 程序校验方向

1. 检查表格物理列数、逻辑列数与数据数量是否一致。
2. 检查同一 C 中是否包含互斥材料、方法或位置。
3. 检查独立单元格值是否被错误合并为一个状态。
4. 表格行数只能生成覆盖率候选，不能直接判定模型遗漏。

## 5. 公式信息的规则抽取

### 5.1 先判断公式是否值得抽取

公式满足以下任一条件时才属于必须抽取：

1. 正文明确将公式作为计算关系、控制关系、临界关系、参数关系或当前结论；
2. 正文明确说明两式等价、变换或化简；
3. 公式直接表达当前规则目标量与输入量的关系，遗漏会使事实不完整；
4. 初稿已经抽取该公式，但公式正文、等式两侧或目标量缺失。

中间推导、背景公式、重复正文结论、只有式号、变量无法辨认或与正文目标量不一致的公式不抽取。

### 5.2 严格区分两类公式

#### A 类：普通计算式、控制式或参数关系

完整公式放在箭头中：

```text
R: 对象|适用状态 —[完整公式]→ 目标量或关系|含义
```

公式不放在左右两端充当对象或状态。

#### B 类：公式等价、恒等变形或明确化简

只有正文明确说明两式之间存在变换时，完整公式才放在箭头两端：

```text
R: 式号|完整原公式 —[等价于/可化简为/变换为]→ 式号|完整结果公式
```

“原公式、简化公式、完整公式、Uao”等占位内容不能代替公式正文。

### 5.3 正例：普通公式位于箭头中

真实包：`context_000896`。

正文说明电弧电压与弧长的关系见式（2-39），完整公式为：

```text
Ua = Uao + EL
```

参考 DSL：

```text
规则组1
C: 无
R: 焊接电弧|弧长变化 —[Ua=Uao+EL]→ 电弧电压|与弧长的关系
```

这是普通目标量关系，不应写成“式(2-39)在左端、目标量在右端”的公式变换。

### 5.4 正例：公式化简时两端都必须完整

真实包：`context_000540`。

正文明确说明：当 `K0/(R0+B0K0)=K1` 且 `L≈0` 时，式（5-30）可化简为式（5-31）。这属于 B 类公式变换。

```text
规则组1
C: K0/(R0+B0K0)|等于K1 + L|约等于0
R: 式(5-30)|\frac{U_o}{U_g}=\frac{K_0K_2R}{T_2LS^2+(R+B_0K_0)T_2S+K_0K_2B_2R}=\frac{\frac{K_0K_2R}{R+B_0K_0}}{\frac{T_2L}{R+B_0K_0}S^2+T_2S+\frac{K_0K_2B_2R}{R+B_0K_0}} —[可化简为]→ 式(5-31)|\frac{U_0}{U_g}=\frac{\frac{K_0K_2R}{R_0+B_0K_0}}{T_2S+\frac{K_0K_2B_2R}{R_0+B_0K_0}}=\frac{\frac{1}{B_2}}{\frac{T_2}{K_1K_2B_2R}S+1}
```

两端不能只写“原公式”和“简化公式”，否则图中虽有两个节点，却没有保存公式知识。

### 5.5 反例：普通反应式被放到结果端

真实包：`context_000904`。

正文给出 CO2 在电弧高温下的分解反应：

```text
CO2 ⇌ CO + 1/2 O2 - Q
```

错误结果：

```text
R: CO2气体|电弧高温作用 —[发生]→ 分解反应|CO2 ⇌ CO + 1/2 O2 - Q
```

该反应式是普通关系，应放入箭头：

```text
规则组1
C: 焊接方法|CO2焊
R: CO2气体|受电弧高温作用 —[CO2⇌CO+1/2O2-Q]→ 分解反应|发生
```

### 5.6 反例：正文目标量与关联公式不一致

真实包：`context_000900`。

正文称式（3-21）用于近似求焊接熔池长度 `L`，但上下文包中的公式实际为温度场：

```text
T(R,x)=q/(2πλR) · exp[-v(x+R)/(2a)]
```

公式中没有目标量 `L`。模型仍把该式写成熔池长度规则，属于证据绑定错误。正确处理是当前包不生成公式规则，等待补齐正确的式（3-21）或修复上下文资源关联。

### 5.7 公式专项矫正方向

#### 提示词方向

1. 在生成公式前先内部分类为普通公式、公式变换或不抽取。
2. 普通公式只能位于箭头，公式变换才允许完整公式位于两端。
3. 要求正文目标量、公式左端目标量和变量解释一致。
4. 任一侧公式缺失、只有式号或存在占位词时，不生成公式变换。

#### 输入组装方向

1. 将公式正文、式号、前后解释段和变量释义绑定为同一公式证据单元。
2. 保留原始 LaTeX，不用 OCR 简写替换上下标、分式和运算符。
3. 一个正文句引用多个公式时，显式传递引用关系，避免相邻公式错绑。

#### 程序校验方向

1. 检查普通公式是否位于箭头关系字段。
2. 检查公式变换两端是否都含完整等式，而非占位词。
3. 比较正文目标量、公式左端符号和 R 右端目标量是否一致；不一致时进入人工审核。
4. 变量或单位缺失只生成审核候选，不自动补全。

## 6. 生成阶段与反思阶段的职责

### 6.1 生成阶段

生成阶段负责第一次建立完整规则：

1. 判断资源相关性；
2. 恢复图片、表格和公式的语义结构；
3. 收集并筛选约束；
4. 按 C 后跟全部对应 R 的顺序输出完整 DSL；
5. 不依赖后续反思替自己完成基础抽取。

### 6.2 反思阶段

反思不是第二次全量生成，而是对初稿的最小修改或补充。审核优先级应为：

1. 规则组划分和 C 作用域；
2. 多前提是共同条件还是独立因素；
3. 方向、对象、状态、关系、数值和单位；
4. 截断关系、属性自环和重复规则；
5. 当前主题下明确且必须抽取的遗漏；
6. 图片、表格、公式中的必须抽取内容；
7. 表达形式。

资源存在本身不能触发 `ADD_R` 或 `ADD_GROUP`。只有能定位到明确证据且确认属于“必须抽取”时，反思才能补充。

## 7. 推荐的多模态输入结构

建议每个上下文包向模型提供以下结构，而不是简单拼接 OCR 文本：

```text
标题路径
核心正文
统领当前核心正文的临近内容
候选约束及各自来源范围

图片资源：
- 图片ID、图题、页码、原图
- 与当前候选相关的局部裁剪
- OCR文本及坐标

表格资源：
- 表题、脚注、图例
- 展开后的层级表头路径
- 单元格值、行列坐标、合并信息
- 原始表格图片或局部裁剪

公式资源：
- 式号、完整LaTeX
- 正文引用句
- 变量解释
- 前后相邻公式及引用关系
```

模型仍接收原始图片，但程序需要提供结构化定位信息，降低模型在大型表格或整页扫描图中自行寻找证据的负担。

## 8. 验收标准

### 8.1 图片规则

- 数值已绑定到正确视觉属性；
- 图号和绘图样式未进入领域图；
- OCR 修正可回溯到可辨图片；
- 无法辨认内容未被猜测。

### 8.2 表格规则

- 每条规则可回溯到完整表头路径；
- 合并单元格作用域正确；
- 独立材料、方法、位置和方案已拆分；
- 图例缺失时未推断等级；
- 大表覆盖率仅用于抽样检查，不替代语义审核。

### 8.3 公式规则

- 已区分普通公式和公式变换；
- 普通公式位于箭头中；
- 公式变换两端均为完整公式；
- 正文目标量、公式目标量和规则目标量一致；
- 没有式号或占位词替代公式正文。

## 9. 当前最优先的改进项

1. 为表格建立稳定的层级表头展开与单元格来源坐标，优先解决错列和合并单元格问题。
2. 为视觉核对候选提供局部图片裁剪，优先解决尺寸属性、符号、单位和 OCR 猜测问题。
3. 在模型调用前增加公式证据绑定和公式类型标记，优先解决普通公式与公式变换混用问题。
4. 在 Viewer 中同时展示规则字段与精确证据位置，使人工反馈能够直接定位图片区域、表格单元格或公式单元。
5. 使用真实问题包持续构建少样本示例，但示例应覆盖不同错误类型，避免大量重复因果规则只强化格式而没有强化多模态判断。
