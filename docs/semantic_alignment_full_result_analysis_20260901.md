## 1. 结论

本次全量运行在工程协议层面完成：5 个生命周期轮次结束，当前轮次所选 object alignment package 和 concept admission 调用均有成功结果，输入指纹、记忆版本、规则/状态频次和概念引用不变量均可追溯。

但当前产物**不应直接作为最终知识图谱或参数推荐输入**。阻断发布的主要原因不是 package 失败，而是结果口径和已验证语义错误：

1. `lifecycle_report.json`中的“最终对象状态”只复制了第 4 轮 H3 产物，共 12,131 条源状态；全量输入实际有 19,470 条源状态。该对齐使用 495 个已注册概念的旧记忆，第 4、5 轮准入结束后的最终库已有 615 个概念，但没有再执行最终全量对齐。
2. 概念“热阴极”错误保留别名“钨极”。模型审核理由明确写明二者“不可互换”，模型输出的别名也是空列表，但事件组装回退到了候选旧别名。结果中 74 条唯一源状态、198 次规则出现的“钨极”被确定性标为“热阴极”。这是已由原始审核记录和对象语义记录共同证实的语义误对齐。
3. 状态数值规范化存在系统性单位截断和误识别。已确认包括 `Hz -> H`、`MPa -> M`、`kg/h -> k`、`atm -> a`，以及把 `m/min`、`cm/min`先按长度换算为 `mm`而丢失速率维度；化学式和焊丝牌号也会被误识别为数值加单位。
4. 全部三层产物按最新记录拼接后虽恰好覆盖 19,470 条源状态，但只能代表各层准入前的历史快照：`MATCHED` 11,684 条，记录匹配率 60.01%，按规则出现频次加权为 68.63%。这不是 615 概念最终记忆上的结果，也不是语义准确率。
5. 仓库没有语义对齐人工金标准。协议成功率、结构不变量和匹配率不能替代结构、核心概念、状态主语、算子与量值的人工准确率门禁。

综合判定：**运行完成，工程可恢复性通过；结果发布门禁不通过。**

## 5. 已确认的语义错误

### 5.1 “钨极”被错误对齐到“热阴极”

原始候选“热阴极”带有旧别名“钨极”。准入模型返回：

- `canonical_name = 热阴极`；
- `aliases = []`；
- 理由明确说明“钨极常作为热阴极使用，但二者是具体实例与类别的关系，不可互换”。

事件组装使用了`decision.aliases or candidate.aliases`，空列表触发回退，最终概念仍保留“钨极”别名。所有三轮对象产物因此把“钨极”以`EXACT_ALIAS`匹配到`concept_a20617c5df3e`（热阴极），影响 74 条唯一源状态、198 次规则出现。

该错误同时说明：当前“模型门禁通过 + 正式库名称唯一”仍不足以保证别名质量；组装逻辑可能覆盖模型已作出的否定判断。

### 5.2 数值与单位规范化错误

跨层完整拼接得到 2,468 条带 quantity 的规则状态，其中 344 条发生单位换算。未知单位原样保留本身是设计行为，但原始记录中可确认以下并非“未知单位”，而是解析错误：

| 错误模式 | 唯一记录 | 累计出现 | 实际表现 |
| --- | ---: | ---: | --- |
| `Hz`被截为`H` | 49 | 126 | `30Hz -> value=30, unit=H`，`z`进入 dimension/surface |
| `MPa`被截为`M` | 22 | 50 | `500MPa -> value=500, unit=M`，`Pa`残留在 surface |
| `kg...`被截为`k` | 16 | 24 | `6.1kg/h -> value=6.1, unit=k` |
| `atm`被截为`a` | 11 | 27 | `1atm -> value=1, unit=a`，`tm`残留在 surface |
| `m/min`按长度换算 | 136 | 249 | `3~4m/min -> 3000~4000mm`，`/min`从单位移到 surface |
| `cm/min`按长度换算 | 58 | 93 | 速率维度被拆开，只保留`mm` |
| 化学式误识别为 quantity | 24 | 38 | `Al2O3 -> value=2, unit=O3` |
| 焊丝牌号误识别为 quantity | 23 | 187 | `H08Mn -> value=8, unit=M` |
| 复合单位被截断 | 5 | 5 | `W/(m²·K) -> unit=W/(m` |

根因可以从结果和实现共同定位：已知单位分支使用`re.IGNORECASE`且没有右边界，导致小时`h`抢占`Hz`、米`m`抢占`MPa`、开尔文`K`抢占`kg`、安培`A`抢占`atm`；复合单位又会被已知单位前缀提前截断。通用单位分支还会把化学式和牌号中的数字片段当作标量。

这些错误会直接污染`canonical_surface`、`operator_family`、quantity 值和单位，不适合进入参数推荐链路。

### 5.3 终局门禁未接受项没有得到可恢复结论

7 个模型`APPROVE`被确定性重复门禁改为`NOT_ACCEPTED`：“缩颈”“氦”“氩”“液柱”“氧”“钢瓶”“焊瘤”。它们最终既未批准也未自动转为`MERGE`，在现有跨层产物中合计 77 条唯一源状态、133 次出现均为`PROPOSED`。

确定性门禁阻止重复概念是正确的，但终局流程应生成明确的 merge/alias 审核任务，或把冲突所有者写入结果；仅以`NOT_ACCEPTED`结束会丢失可操作的修复路径。

## 9. 建议修复与重跑顺序

1. **修复别名组装并订正“钨极”数据。** 对模型返回的空`aliases`使用空列表，不回退候选旧别名；单独重审“热阴极/钨极/钨极材料”，清除错误别名后使受影响缓存失效。
2. **修复单位词法边界。** 已知单位应区分大小写并要求完整边界；先识别`Hz`、`MPa`、`kg/h`、`m/min`、`cm/min`、`W/(m²·K)`等复合单位，再处理单单位；化学式、牌号和公式应有排除规则。把本报告中的真实样例加入回归测试。
3. **统一概念准入政策。** 明确定义哪些“物理量种类/可测属性”是 object，哪些“具体参数/取值”只进状态；按同一规则重审焊接电流、焊接速度、送丝速度、弧长、温度、板厚、气体流量、热输入和电流极性等边界概念。
4. **修复生命周期终局。** 动态生成候选的`DEFER`也必须进入 parked 集；最终报告在存在任何`DEFER`、`FAILED`或`NOT_ACCEPTED`未转为可操作任务时不能标记完全收敛。
5. **在最终冻结记忆上重新全量对齐。** 不拼接不同记忆版本的历史层级文件；最终准入和合并全部结束后，重新评分 6,166 个对象并生成单一正式五件套及全量 19,470 条不变量报告。
6. **修正汇总语义。** `final_object_status_counts`必须来自最终全量 artifact；把 792 条未注册目录拆成 rejected/not-accepted/pending；为派生 intrinsic state 和 condition 分别报告主语绑定率。
7. **建立人工发布门禁。** 按 H0-H3、高频/长尾、ATOMIC/COMPOSED/UNRESOLVED、数值/非数值分层抽样，覆盖已发现的别名、参数边界、复合对象和复合单位问题。人工 gold 通过后才能报告“语义准确率”并导入图数据库。
