# Concept Layer 100条真实规则严格测试

## 数据与运行

- 输入：Rule Extraction前100条真实规则。
- 模型：8003上的`/DATA/jm/llms/qwen3.8-27b`，temperature=0，关闭thinking。
- 实际负载：100条Rule聚合为98个唯一ObjectSeed；96个Seed召回到证据。
- 完整运行耗时：492.684秒，4路并发。
- 输出：51个Rule直接概念、6个仅由层级引入的父概念、150个Rule绑定、10条去重后的直接IS_A。

## 严格通过标准

结构门禁：证据召回覆盖率不低于95%；结果完整率、accepted证据闭合率、定义证据闭合率、绑定完整率和IS_A结构有效率必须为100%；模型或格式校验失败率不高于2%。

语义门禁：98个Seed全部人工审查，资格决策准确率不低于90%；accepted定义逐个核对，正确率不低于90%；输出的直接IS_A逐条核对，精确率必须为100%。无人工Gold时不报告“概念召回率”，避免把生成数量误称为召回率。

## 主要问题

1. 过度拒绝：`元素`、`激光`、`人机界面`、`焊接过程`、`粒子`、`表面能`、`电极距离`等稳定概念，仅因当前证据没有完整定义或父类就被拒绝。概念资格与“能否立即生成定义/父类”仍被模型混在一起。
2. 五个技术失败：`A-TIG焊`、`CMT`、`L-MIG焊`、`焊接噪声`、`逆变式CO2焊机`连续三次违反名称或父类证据约束，最终安全降级为ambiguous，但失败率超过门槛。
3. 三个定义不合格：`大功率低频脉冲TIG焊`把噪声这一偶然属性当定义；`小孔法变极性等离子孤立焊法`把“无缺陷”的评价当定义；`焊接飞溅`错误使用了“飞溅率”的定义。
4. 层级精度高但产量有限：51个accepted直接概念只形成10条去重IS_A。20个父类候选中11次审核通过、9次拒绝；其中`复合焊 IS_A 焊接方法`虽通过父类审核，但Seed整体为ambiguous，未进入组装。11次通过最终去重/资格过滤为10条关系。这是严格证据策略的结果，不应称为父类召回率。
5. 工程可恢复性不足：本次基线测试使用4路并发；测试后项目默认值已调整为16路。当前虽有单Seed故障隔离，但仍缺少逐Seed进度日志及断点缓存。

## 下一轮优化方向

- 将LLM任务拆成两个独立判定：先只判断Seed是不是稳定概念；accepted后再判断定义是否充分。定义不足应保留Concept并令definition为null，而不是拒绝Concept。
- 父类提议也从主Resolution中拆出，避免一个不合规父类让整个概念三次重试后降级。
- 增加定义对象一致性校验，显式禁止用“率、指标、优点、缺点、称誉”替代目标概念定义。
- 建立人工Gold标注后再测概念召回率；当前只能可信报告精确率和证据覆盖率。
- 增加逐Seed缓存、进度事件和失败Seed定向重跑。
