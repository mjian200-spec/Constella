# 反思模块 main/full 双版本

> 历史记录：2026-08-24 的真实包比较完成后，项目已只保留 Full 提示词。Main、Legacy 提示词和 `--reflector-profile` 参数均已删除；以下对比数据仅用于追溯决策。

依据用户提供的反思建议，将反思模块拆成两个可运行profile。两版共用相同的稀疏补丁协议、`C: 无`规则、稳定`[G/R]`地址和本地无效补丁过滤器。

## main：只改最主要问题

`rule_reflector_main` v1只落实四项最高优先级修改：

1. `NO_CHANGES`不是预设结论，完成检查后才能使用；
2. 表格、图片和公式先做“必须抽取/可选补充/不属于规则”相关性判断；
3. 优先检查组级C作用域和多前提独立性；
4. 增加方向错误、独立因素拆分、正确规则禁止重吐和资源可选的示例。

## full：全量修改

`rule_reflector_full` v1在main基础上增加：

- 固定七级审核顺序；
- 表格必须补充的五项联合条件；
- 两类公式表达与公式非强制抽取条件；
- 图片/OCR定向核对条件；
- 属性变化自环检查；
- C内互斥取值和R左侧AND/独立因素判定；
- 命令级事实字段变化检查；
- 方向、独立因素、自环、资源可选、公式可选和公式必需的成对示例。

## 固定40份真实初稿A/B

模型均为本地`qwen3.8-27b`，固定使用同一批generator v10初稿，只重跑反思；并发4，不写Neo4j。

| 指标 | main v1 | full v1 |
|---|---:|---:|
| `NO_CHANGES` | 16/40 | 25/40 |
| 模型输出补丁 | 24/40 | 15/40 |
| 本地过滤后实际变化 | 16/40 | 14/40 |
| 补丁应用失败 | 0 | 0 |
| 运行耗时 | 42.3秒 | 85.1秒 |

关键案例：

- `context_000361`：两版都将“过零慢→消电离快”修正为“过零慢→消电离慢”。
- `context_000272`：两版都把电流极性与保护气体两个独立因素拆成独立R；full保留了MIG焊共同C。
- `context_000830`：两版都识别属性自环；full补回“应用”作为变化来源，表达更完整。
- `context_000481`：两版仍重吐相同R，但本地过滤器使最终文本不变。
- `context_000863`：两版均未因大型表格存在而强制补齐，符合资源相关性规则。
- `context_000012`：两版仍未发现`Hz/H2` OCR问题，说明缺少程序提供的视觉核对候选时，仅靠提示词不稳定。
- `context_000743`：full输出107行补丁，暴露完整审核会在大型表格上退化为大量局部重写；仍需依赖本地过滤和人工验收。

结论：main更短、更快，但更容易对局部表达发出补丁；full对资源可选性更保守、关键语义修复更完整，但耗时约为两倍，且在大型表格上仍可能产生大补丁。默认profile为main，full用于显式高强度测试和复核。
