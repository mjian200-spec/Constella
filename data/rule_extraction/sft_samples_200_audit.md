# 规则抽取 SFT 200 条数据审核记录

审核对象：`data/rule_extraction/sft_samples_200.yaml`

## 数据规模

- 真实上下文包：200 个，ID 无重复。
- 人工金标规则：1267 条。
- 多模态样本：85 个，关联本地原始图片 100 张。
- 路由分布：text 98、text+formula 17、text+image 59、text+image+formula 3、text+image+table 3、text+table 19、text+table+formula 1。
- 章节分布：第1章 2、第2章 61、第3章 28、第4章 34、第5章 35、第6章 37、附录 3。

## 逐项审核口径

每条样本均以 `input.text` 中的标题路径、包条件、核心正文、支撑内容和资源文字化为证据，图片型样本同时保留 `input.images` 的原图路径。审核时逐条确认：

1. C 只承载整组共同适用的场景、范围或实施前提，允许为“无”。
2. R 的左侧是直接参与关系的输入，右侧只有一个对象与状态；多个结果拆成多条 R。
3. `+` 仅表示原文明示共同成立；备选项拆成多条规则，混合气体内部的 `+` 保留在同一状态中。
4. 裸数值必须绑定属性；公式放在箭头中，并以有语义的公式输入和输出连接。
5. 资源出现在上下文包中不等于必须抽取；截断句、问句、无法确认的图像读数和远距内容不补全。
6. C 与对应 R 输入的对象、状态不得完全相同；规则输入和输出不得形成完全相同的状态自环。

## 本轮集中订正

- `context_000018`：将“原子、离子或分子”归纳为气体重粒子，避免把互斥类别留在单一条件中。
- `context_000034`：中性粒子与受激粒子分别建规则，不用“或”隐藏备选分支。
- `context_000052`：室温与 0℃ 两种状态拆开。
- `context_000074`：把“低于或等于沸点”规范为“不高于沸点”。
- `context_001435`：EN、EP 半波拆成两个规则组。
- `context_002026`：圆形、异型只是钢管截面备选，制造链统一写为“卷成钢管”。
- `context_002434`：碳钢与低合金钢分别建组，不合并母材实体。
- `context_000449`：化学反应式单独表达反应物到生成物的等价关系，再连接脱氧抑制链。
- `context_001012`：删除仅由符号下标推测的方向约束，不补造特殊质量条件的缺失结论。
- `context_000792`：删除没有明确评价属性的“整体有利”关系。

使用：

```bash
PYTHONPATH=src python scripts/validate_rule_sft_dataset.py \
  data/rule_extraction/sft_samples_200.yaml --expected-count 200
```

验证覆盖样本数、唯一 ID、输入文本、图片文件、路由与图片一致性、构建说明长度、禁用无规则输出、R 箭头、DSL 可解析性、单一结果以及 C/R 完全重复。最终结果为 200 个样本、1267 条规则和 100 个有效图片引用全部通过。

跨上下文存在两组相同基础事实：Ar、He 均属于惰性气体。它们分别来自独立真实上下文，保留作为不同语境中的重复监督，不属于同一规则内的对象—状态重复。

## 使用注意

`input.images[].path` 是当前工作区的绝对路径。迁移到其他训练环境时需要按数据根目录重映射路径，但不得改变图片与 `unit_id` 的对应关系。
